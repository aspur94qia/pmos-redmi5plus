======================================================================
CATATAN TEKNIS
======================================================================
- Helper JS callAction(cmd, params, btn): POST /action?json=1 dengan
  credentials:'same-origin' (cookie terbawa), header Accept: application/json,
  body form-urlencoded. Tombol di-disable + spinner selama request. Response
  bukan JSON -> anggap sesi habis -> reload. Toast menampilkan d.msg dengan
  warna sesuai d.ok.
- Server: do_action return (ok:bool, msg:str). Jika Accept: application/json
  ATAU query ?json=1 -> self.json({"ok","msg"}) 200. Jika tidak -> redirect
  302 lama (kompatibel form non-JS).
- APKBUILD: sudah include dashboard.html (install ke /etc/vince/dashboard.html)
  dan vince-webui.py (ke /usr/libexec/vince-webui). Tidak perlu diubah.
